1. ABSTRACT 
 
The project “Portify  – AI-Powered Resume-to-3D Portfolio Generator” applies Generative AI to automate the 
creation of modern personal portfolios from resumes. The problem addressed is that converting resume 
information into a well-structured, responsive portfolio normally req uires manual web-development and design 
effort. The proposed system accepts PDF, DOCX, TXT, or pasted resume text, extracts the content, and uses 
Google Gemini to transform it into structured professional information such as personal details, skills, experience, 
education, projects, certifications, and achievements. A React and TypeScript interface then renders the data 
using responsive layouts and interactive 3D visual effects. The system also supports portfolio customization, 
publishing, and contact commu nication. The result is a functional AI -assisted workflow that reduces portfolio 
creation effort while preserving resume-specific content. 
Keywords: Generative AI, Google Gemini, GCP, React, TypeScript, Three.js, Resume Parsing, 3D Portfolio.
